# Network Traffic Monitor

Read-only terminal dashboard for live network traffic on Linux. **Strictly
passive** — captures and displays traffic only; never blocks, filters,
injects, or modifies packets.

## Setup

```bash
sudo apt update
sudo apt install -y libpcap-dev python3-dev build-essential

cd network-traffic-monitor
python3 -m venv --copies venv   # --copies: real binary, not a symlink (needed for setcap below)
venv/bin/python3 -m pip install -r requirements.txt

# Let the venv's python capture packets without running the whole app as root:
sudo setcap cap_net_raw,cap_net_admin=eip $(readlink -f venv/bin/python3)

# Generate the desktop launcher for this checkout and install it into your app menu:
./install-launcher.sh
```

## Run — web dashboard (no terminal needed day-to-day)

Double-click **Network Traffic Monitor** in your XFCE application menu (Whisker
Menu → search "Network Traffic Monitor"), or from Thunar double-click
`traffic-monitor.desktop` in the project folder (first time, right-click it →
Properties → Permissions → "Allow this file to run as a program" if Thunar
doesn't trust it yet). Both are generated by `install-launcher.sh` from
`traffic-monitor.desktop.template` — re-run that script if you move the checkout.

This starts a local web server and opens your browser to
`http://127.0.0.1:8765`. Pick an interface, click **Start capture**. No `sudo`
needed each time — the capability was granted once via `setcap` above. Click
**Stop capture** or just close the tab when done (closing the tab does not
stop the background server process — quit it from your app switcher / `pkill
-f src.web_main` if you want to fully stop it).

To run it manually instead of via the launcher:

```bash
venv/bin/python3 -m src.web_main             # opens browser automatically
venv/bin/python3 -m src.web_main --no-browser --port 9000
```

## Run — terminal dashboard (original `rich` UI)

```bash
venv/bin/python3 -m src.main            # interactive interface picker
venv/bin/python3 -m src.main -i wlp2s0  # explicit interface
venv/bin/python3 -m src.main --auto     # auto-pick first UP interface
```

Ctrl+C to stop.

If you skipped `setcap`, run either entry point with `sudo venv/bin/python3 -m ...` instead.

## Layout

- `src/interfaces.py` — interface discovery/selection (`ip -j addr` + scapy cross-check)
- `src/parser.py` — raw packet -> normalized `PacketInfo` (protocol, IPs, ports)
- `src/stats.py` — thread-safe throughput + per-device + per-connection aggregation
- `src/sniffer.py` — background capture thread (scapy `AsyncSniffer`, `store=False`)
- `src/ui.py` — `rich` live terminal dashboard
- `src/main.py` — terminal CLI entry point
- `src/webapp.py` — FastAPI backend (capture control + JSON stats API)
- `src/web_main.py` — web dashboard entry point (starts server, opens browser)
- `src/static/` — dashboard frontend (vanilla HTML/CSS/JS, no build step)
- `run.sh` — launches the web dashboard with the venv's python
- `traffic-monitor.desktop.template` / `install-launcher.sh` — generates and installs the double-click app-menu launcher (path-independent, safe to commit)
